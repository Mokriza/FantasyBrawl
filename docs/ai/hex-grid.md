# Гексовая сетка

Вся геометрия — в `src/core/hex.ts`, чистые функции без зависимостей. Эталонный источник по алгоритмам — статья Red Blob Games «Hexagonal Grids» (redblobgames.com/grids/hexagons). Если сомневаешься в формуле — сверяйся с ней, а не выдумывай.

## Соглашения

- **Ориентация:** плоский верх (flat-top). Столбцы вертикальные.
- **Логика:** осевые координаты `{ q, r }`. Третья кубическая координата вычисляется: `s = -q - r`.
- **Хранение и поле 9×9:** прямоугольник в offset-координатах `odd-q` (нечётные столбцы сдвинуты вниз), `col ∈ [0, 8]`, `row ∈ [0, 8]`; размер — `config.arena.cols` и `rows`. Число столбцов обязано быть нечётным: генератор арены ставит препятствия парами в зеркальных столбцах `col` и `cols − 1 − col` (строки у пары разные) и одиночные — на центральном столбце, который нужен ничей (проверяет `validate-content`). Подробности — `game-rules.md`, «Генерация арены». Offset используется **только** для генерации поля и отрисовки. Вся игровая логика — в осевых.
- **Ключ гекса** для `Record`/`Map`: строка `"q,r"`. Функции `hexKey(h)` и `parseHexKey(k)`. Объекты-гексы как ключи `Map` не использовать — сравнение по ссылке.
- **Стороны:** сторона `A` стартует в столбцах `col 0–1`, сторона `B` — в `col 5–6`.

```ts
interface Hex { readonly q: number; readonly r: number }
```

### Конверсия odd-q

```ts
function offsetToAxial(col: number, row: number): Hex {
  const q = col;
  const r = row - (col - (col & 1)) / 2;
  return { q, r };
}
function axialToOffset(h: Hex): { col: number; row: number } {
  const col = h.q;
  const row = h.r + (h.q - (h.q & 1)) / 2;
  return { col, row };
}
```

## Линия между гексами

Для линии видимости и форм `line`. Линейная интерполяция в кубических координатах с округлением.

```ts
function hexLine(a: Hex, b: Hex): Hex[] {
  const n = distance(a, b);
  // сдвиг на эпсилон убирает неоднозначность, когда линия идёт ровно по ребру между гексами
  const eps = { q: 1e-6, r: 2e-6, s: -3e-6 };
  // для i в [0..n]: cubeRound(cubeLerp(a + eps, b + eps, i / n))
}
```

- **Один эпсилон на весь проект.** Его знак определяет, в какую сторону «сваливается» линия по ребру. Если поменять — изменятся линии видимости и сломаются тесты. Это ожидаемо и правильно: такие тесты и нужны.
- Линия включает начальный и конечный гексы. Для проверки обзора смотрим только промежуточные: `line.slice(1, -1)`.
- `cubeRound` — стандартный: округлить три координаты, пересчитать ту, у которой наибольшая ошибка округления.

## Достижимость и поиск пути

Стоимость шага неоднородна (зона контроля, Яма), поэтому поиск — Дейкстра, а не BFS.

```ts
interface Reachable { readonly cost: number; readonly path: readonly Hex[] }

function reachableHexes(
  state: BattleState, heroId: HeroId, apBudget: number
): Map<string, Reachable>;
```

- Стоимость шага из `from` в `to`: `1`, + `1`, если `to` — Яма. Зона контроля в стоимость **не** входит: она стала атакой по возможности, см. `game-rules.md` §4.
- Непроходимы: гексы вне поля, препятствия с `blocksMovement`, гексы с героями и призванными юнитами.
- Каждый достижимый гекс несёт ещё и список врагов, которые ответят атакой по возможности на пути к нему.
- Тай-брейк при равной стоимости: меньше спровоцированных атак, затем меньшее число шагов, затем порядок `DIRECTIONS`. Путь детерминирован.
- Поскольку набор спровоцировавших зависит от всего пути, а не только от последнего шага, поиск релаксирует метки до стабилизации, а не закрывает каждый гекс один раз. На 49 гексах это ничего не стоит.
- На 49 гексах Дейкстра на простом массиве быстрее кучи. Кучу не подключать.

## Пиксели (только `ui`)

Эти функции живут в `src/ui/`, не в `core`: пиксели — не правила.

```ts
// size — радиус гекса (от центра до вершины)
function hexToPixel(h: Hex, size: number): { x: number; y: number } {
  const x = size * (3 / 2) * h.q;
  const y = size * Math.sqrt(3) * (h.r + h.q / 2);
  return { x, y };
}
function pixelToHex(x: number, y: number, size: number): Hex; // обратная + cubeRound
```

## Обязательные тесты `hex.ts`

- `distance` симметрична и равна 0 только для одинаковых гексов.
- `neighbors` каждого гекса находятся на расстоянии 1.
- `offsetToAxial ∘ axialToOffset` = тождество на всём поле (тест проверяет прямоугольник 7×7, математика от размера не зависит).
- `hexLine(a, b)` имеет длину `distance(a, b) + 1` и соседние элементы на расстоянии 1.
- `hexLine` детерминирована для «рёберного» случая (закреплённый снимок).
- `reachableHexes` и зона контроля: зафиксированные сценарии на выход из зоны, шаг внутри зоны, повторный выход от того же врага за один ход и дальний класс, который зону не держит.
